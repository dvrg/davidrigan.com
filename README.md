# davidrigan.com

Personal website for David Rigan. Built with Next.js 15, React 19, Tailwind CSS v4, and Motion.

## Getting Started

```bash
npm install
npm run dev
```

## Available Scripts

| Script                | Purpose                             |
| --------------------- | ----------------------------------- |
| npm run lint          | ESLint (Next.js + TypeScript + MDX) |
| npm run lint:strict   | ESLint in strict mode               |
| npm run format        | Auto-format with Prettier           |
| npm run format:check  | Check formatting without writing    |
| npm test              | Run tests once                      |
| npm run test:watch    | Run tests in watch mode             |
| npm run test:coverage | Run tests with coverage report      |
| npm run typecheck     | TypeScript errors                   |

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Based on Nim Template

This project uses the Nim template designed to combine minimalism with delightful animated components powered by [Motion-Primitives](https://motion-primitives.com).
